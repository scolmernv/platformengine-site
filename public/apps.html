Live Apps

AI applications running live on a DGX Spark: chat with Nemotron, see what AI usage costs, build prospecting packages and AI factory configurations, and watch intelligent routing decide.

  • Chat Talk to NVIDIA Nemotron, running on a DGX Spark. Sign-in required.
  • Tokenomics Usage and cost of the Agent Studio and this site: tokens, models, agents and the DGX Spark, with what the same work would cost on Claude, ChatGPT, Gemini and Microsoft. Sign-in required.
  • APO Customer Profile Builds a prospecting package of Word documents for a target company, using NVIDIA Nemotron running on a DGX Spark. Sign-in required.
  • AI Factory ERA Configuration Builds a Word configuration report for an NVIDIA ERA AI Factory from a bill of materials and prospect notes, for Cisco, Dell, HPE, Lenovo, Supermicro or Red Hat. Sign-in required.
  • Intelligent Routing Watch NVIDIA Switchyard route each question live between local Nemotron on a DGX Spark and hosted Nemotron, with the model, tier, latency and tokens shown for every answer. Sign-in required.

Apps may be temporarily unavailable during maintenance.
